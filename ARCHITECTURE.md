# Architecture
Five-agent LLM pipeline for corporate bond factor replication, bias detection, and extension. Two-layer corpus: anchor (BBW + short-term reversal + six-month momentum, n=3, data-matched, fully manual; KPP methodology-exemplar and Duraj-Giesecke showcase sit outside it) + scale (10–20 papers, pipeline + paper-statistics verification).
Every implementation is validated and verifiable.

## Research Questions
RQ1 — Librarian extraction fidelity on the gold-standard set (BBW, KPP, DG): field-level per-field accuracy, multi-model agreement rate, failure taxonomy (field-level reconstruction, NOT strategy-class routing).
RQ2 — Quant compilation fidelity + coverage: given a correct specification, can the system implement the intended strategy faithfully and refuse safely when it cannot, and what coverage does the audited deterministic substrate cost? Anchor fidelity = evaluation-contract §7 **gates 1–2** — construction invariants (direction, group count, weighting, signal lag, holding period, leg identities) + rulebook byte-equality modulo the authorised register (G2) — per **v1.6 / D-Q17** (2026-08-14; supersedes O5 / D-Q1: the §7 gate-5 within-pipeline bias-mechanism differential is retained but reported as a non-gating RQ3-facing diagnostic, RQ3's own uncorrected-vs-corrected machinery; gates 3–4 external level comparisons remain non-gating). Layered coverage C_semantic / C_binding / C_execution / C_end-to-end over the frozen candidate set; FIR (headline safety) beside FRR; fraction of the corpus implementable via audited families vs correctly refused (typed refusal taxonomy).
RQ3 — Bias prevalence (Auditor), differential: each strategy run across its correction lattice, as-published (all-OFF) vs corrected (all-ON), bias = the gap; effect sizes with CIs (survival counts secondary); scoped, partial estimate over enumerated biases. Audit set fixed at 3 (str pilot; mom6 + drf confirmatory, locked — D-A59); crf is RQ1/RQ2 only (RQ3-excluded). Clean on the anchor set + traded-liquidity negative control; scale layer weaker/confounded.
RQ4 — Extension evaluation (Scientist): starting from a bias-corrected strategy, can the system propose extensions that are executable, audit-clean (the extended candidate re-audits with every correction still applied and none reversed), and survive a pre-registered statistical evaluation? NOT repair — the parent is fully corrected (from the Auditor, or by computing the corrected run deterministically), so there is no residual defect to fix. Entry is conditional on RQ3: a strategy enters only where a validated correction meaningfully removed performance — its RQ3 effect survived BH-FDR (within-strategy adjusted q≤0.10), exceeded the materiality floor θ=10 bp/month, AND reduced the premium (Δ<0); all three hold. The corrected parent is held fixed; extensions build on it and can never reverse an RQ3 correction. Two phases: proposal development (where all formal selection happens — BH-FDR jointly over each source's audit-clean proposals, then CPCV qualification) and one protected holdout (2022-01..2025-09, 45 months — the complete-months span of the `/data/holdout/` partition; the pull ends 2025-09-30, ruled by post-tag amendment SC-SCI-12 (2026-08-07) correcting SC-SCI-10's false 48/2025-12 and superseding the tag's 2022–2024 window). The 45-month window's frontier-completeness citation (`docs/data/registers/citations_verified.md` §3) is verified, so the 45-month window is the sole reported evaluation window; SC-SCI-15 (2026-09-01) retired the tagged 36-month sensitivity sub-window. The holdout is descriptive (a sign, a paired difference, an interval), not a verdict. The LLM proposes only — it makes no judgement and runs no statistical evaluation.
Each RQ has a structurally independent validation path — failure in one component cannot contaminate another.

## Agent Hard Constraints

**Librarian**: dual LLM extraction (stack committed — `docs/thresholds.yaml` `librarian.model_stack`). A field is STATED only if both models agree on value AND verbatim quote. No self-reported confidence scores. UNKNOWN is a valid value, not an error.

**Quant**: deterministic compilation — StrategySpec → adapter → QuantConfig → audited runner. Routing is deterministic (closed-enum family table + typed refusal); an LLM may appear only as a post-refusal explainer over typed outcomes (designed; NOT yet built — no LLM currently sits anywhere in the Quant path). The 8-iteration cap applies to the Librarian's retrieval loop if and when the contract's §3.6 gate triggers it. Modifications to /agents/quant/library/ require manual review + all regression tests passing.

**Auditor**: differential comparator — runs each strategy across its correction lattice (up to 2^5=32 cells) through the same module; the headline is the gap between the as-published (all-OFF) and fully-corrected (all-ON) cells, decomposed into per-correction and interaction effects. NOT single-run inspection (single-run on a pre-cleaned pipeline finds nothing). Checks 1–4 differential; check 5 (multiple-testing, mt_flag) is a non-differential flag, off-lattice. /agents/auditor/checks/ is deterministic — zero LLM calls. LLM appears only in the explainer (agents/auditor/explainer/, post-verdict, numeric-verifier-gated; LLM half built but Phase-F-gated, deterministic renderer as stand-in). Refuses to opine when required fields are UNKNOWN or INFERRED without a matching rule. Silent iteration until pass is forbidden — it is p-hacking.

**Scientist**: input = a correction-sensitive strategy (entry = its RQ3 correction effect is an FDR-survivor ∧ material (>θ) ∧ premium-reducing (Δ<0); see RQ4). It EXTENDS, never repairs — "repair" is banned from code, comments, logs, schemas, and output. Extensions build on the fully corrected parent (held fixed) and may never reverse a correction; every candidate sits at or above the corrected lattice point. Fixed 6 proposals/strategy (NOT 4–8), committed to docs/scientist_protocol.yaml (git tag scientist-prereg) before the first generation run; invalid/duplicate proposals are data, not retried. The wall: no generative call ever receives a realised performance statistic (structural — allow-listed context). Three proposal sources (random / retrieval / generative LLM) share one schema, gate stack, and evaluator; BH-FDR over each source's audit-clean proposal family, then CPCV-qualified survivors advance to the single holdout. 13 typed refusal codes (a distinct enum from the shared-evaluation refusal registry). A significant-but-wrong-signed extension is a finding (wrong_signed), not a refusal; improvement direction is the realised corrected-parent premium sign, not the paper's claim (disagreement recorded, not resolved).

**Reporter**: NEVER regenerates numbers from prose. Every numeric token in the output is asserted against typed pipeline output by agents/reporter/verify.py before commit (deterministic, no LLM anywhere in the Reporter).

## StrategySpec Schema
Every fact-bearing field is an `Inherited[T]` carrying value, tag (STATED | INFERRED | DESIGN | UNKNOWN), and evidence (STATED requires a verbatim quote + locator; INFERRED requires a rule_id — supplied by the D25 adapter transform table, agents/librarian/adapter/transform_table.py, NOT the reserved-but-unused docs/librarian/specs/inference_rules.md — and retains the original paper quote; DESIGN marks deliberate project substitutions). Schema v1.1 is built and shipped (`agents/librarian/schema/`).

## Replication Success Criterion
**Superseded (2026-07-13): the ±15% primary criterion is retired → evaluation contract §7 hierarchical gates (see RQ2). The paragraph below is retained as history.**
Applies to the data-matched anchors (BBW, str, momentum) on the uncorrected/as-published panel. Primary: Sharpe AND factor loadings AND per-quintile spreads all within 15% tolerance (thresholds.yaml). Coincidental Sharpe match alone is NOT success. KPP is exempt — validated methodologically only (correct IPCA procedure), NO ±15% target, as its ICE-based numbers are unrecoverable on WRDS-MMN. Secondary diagnostic: bootstrap CI overlap reported as an additional column alongside the primary criterion.

## Testing Requirements
- All agents: unit tests in /tests/unit/
- Auditor: synthetic bias injection tests verifying 100% recall for every injected bias type
- Library modules: unit test on synthetic data with known analytical answer + regression test against paper headline metric (data-matched anchors) or published procedure (KPP)
